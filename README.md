# Motorcycle Rental Company

## 🚀 Project Overview
The **Motorcycle Rental Company** is a web-based application that enables users to browse, filter, and book motorcycles effortlessly. Administrators can manage motorcycles, view statistics, and handle customer bookings efficiently.

---

## 📌 Features

### 🏍️ For Customers:
- Browse available motorcycles.
- Register and log in.
- Book motorcycles for selected days.
- Complete the payment process using a credit card.
- Provide feedback on rental experiences.

### 🔧 For Admins:
- Manage motorcycle listings.
- Monitor bookings.
- Access user data, booking details, and customer feedback.
- View system-generated statistics and reports.

---

## 🛠️ Technologies Used
- **Backend:** PHP
- **Frontend:** HTML, CSS
- **Database Management:** phpMyAdmin (MySQL)

## 📥 Installation Guide

### 🔹 Step 1: Install XAMPP
1. **Download XAMPP**:  
   - Visit [Apache Friends](https://www.apachefriends.org/index.html).  
   - Download the latest version for your OS (Windows, macOS, or Linux).  
2. **Install XAMPP**:  
   - Run the installer and follow on-screen instructions.  
   - Select the necessary components: **Apache, MySQL, PHP, phpMyAdmin**.  
   - Choose the installation directory (default is recommended).  
3. **Start XAMPP Services**:  
   - Open **XAMPP Control Panel**.  
   - Start **Apache** and **MySQL** by clicking the "Start" button next to each.

---

### 🔹 Step 2: Set Up the Database
1. **Open phpMyAdmin**:
   - Open a web browser and go to [`localhost/phpmyadmin`](http://localhost/phpmyadmin).
   - Log in using the default credentials (**Username:** root, **Password:** *leave blank*).
2. **Create the Database**:
   - Place the project files inside the `htdocs` folder in your XAMPP installation directory.
   - Open a web browser and go to [`localhost/Group82/database`](http://localhost/Group82/database).
   - Two files will be displayed: `createDB.php` and `final1.sql`.
   - Click on `createDB.php` to automatically create the database and set up the system.

---

### 🔹 Step 3: Run the Application
1. Open a web browser.
2. Enter [`localhost/Group82`](http://localhost/Group82) in the address bar.
3. Start using the **Motorcycle Rental Company** system!
